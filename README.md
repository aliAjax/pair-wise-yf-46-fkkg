# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 广告兑现台账（/ads）

- 每条广告登记合同时段窗口、时长、应播次数；播出后登记实际起止，与本地播出日志对账，给出 待播/已兑现/部分兑现/漏播/错时段/偏差过大 结论。
- 串联单、合同或播出日志一改动，兑现结论即失效并按新计划重算；漏播与偏差过大的广告自动进入补播队列。
- 补播时段有容量上限，排满后多余条目排队等位；补播完成会回写一条「补播」播出记录并释放容量。
- 合同方回执与本地记录不一致时两条都保留并标出差异，等主编核对；已有确认结果后晚到的回执标记「晚到未采信」，不顶掉已确认结论。
- 旧串联单没有合同信息，升级时按广告条目自动补默认合同（窗口取硬时间或计划时间起 30 分钟、应播 1 次），并标注待核对。

## 技术栈

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。
